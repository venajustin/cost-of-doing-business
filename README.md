## Pitch

Stock market simulator where you play as a broker in the 1950's. 
You must walk around the NYSE and use hand singnals to buy and sell shares each day. 
The hand is controlled with the keyboard, 12345 keys control fingers while mouse buttons move the wrist and arm. 
This allows you to create most of the symbols used in the old stock trading circles.

## Current state

The hand motions and animations are completed, there are models for trading booths. 
There are some NPC's that are supposed to represent other traders, right now they just pathfind to the player.
